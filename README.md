# QA Automation - Sauce Demo (Cypress)

Proyecto de pruebas E2E con Cypress para el demo de Sauce Demo.

Instrucciones rápidas:

- Instalar dependencias: `npm install`
- Ejecutar tests: `npx cypress open` o `npx cypress run`

Repositorio destino: https://github.com/R-Mutt1917/QA-Automation-xAcademy
